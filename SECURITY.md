# Security Policy

Lineo is a small open source project that runs entirely in your browser. Images you open are processed locally and are not uploaded anywhere.

## Supported versions

Only the latest version on the `main` branch is supported.

## Reporting a vulnerability

If you find a security problem, please report it privately. Please do not open a public issue.

1. Go to the "Security and quality" tab of this repository.
2. Click "Report a vulnerability".
3. Describe what you found and how to reproduce it.

I will read reports as soon as I can. This is a hobby project, so I can't promise a fixed response time.
